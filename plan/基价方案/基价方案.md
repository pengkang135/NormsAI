# 消耗量子目基价方案（泰国 2026 参考基价）

> 状态：Phase 0~6 已执行并提交。详见文末「执行进度」。
> 脚本在 `temp/scripts/`，中间产物在 `temp/`。

## 1. 问题

5 册的 `Consumption` 单价在 2026-08 人材机标准化时被全库清 0，价格改由
`resource_master.resource_price` 按国别承载 —— 但那张表当时 0 行。于是定额有完整消耗量、没有基价：

- 前端 `start.py:834` 和综合单价导出 `src/export_norms.py:183` 都读 `cons_Price`，全拿到 0
- `Norm` 的 6 个价格列还留着来源书带来的旧中国基价，与清 0 后的 `Consumption` 不自洽

目标：以 CostSpread 泰国报价为准、中国基价为底，做一版**截止 2026 年的泰国参考基价**。
要求可参考、可追溯，不要求精确。

## 2. 探查结论（这些结论决定了方案形态）

### 2.1 中国基线已经在库里，不需要去 CostSpread 捞

`resource_alias.src_Price` 保留了清 0 前的原始单价：12,861 条，覆盖 9,245/13,981 个资源，
按 `content_refs` 加权 **78.4%**（材料 85% / 机械 64% / 人工 98%）。

两个必须处理的坑：

- **标准单位价 = `src_Price / unit_factor`**。柴油 8976 元/t ÷ 1000 = 8.98 元/kg，与直接 kg 别名一致。
  `unit_factor <> 1` 只有 47 条，但不除就是千倍级错误。
- **同一资源跨来源书有 2 倍价差**（普工 74.3 → 151.2，分别是北京2012 与 PK2026 水平）。

### 2.2 取值规则必须用中位数，不能用 max，也不能按来源书定年份

试过三种规则，只有中位数站得住：

| 规则 | 问题 |
|---|---|
| max | 柴油→8976（把 元/t 当 元/kg）；水泥砂浆 1:2 = 798.81 > 1:2.5 = 289.39，破坏单调性 |
| 按 `src_cons_ID` 区间定年份 | PK2026（`src_cons_ID >= 20000000`）只覆盖 356 个资源，且价格并不系统性更高：柴油 5.7 vs 8.98、防锈漆 10.0 vs 16.3、界面剂 7.11 vs 2.01，两个方向都有 |
| **中位数** | 柴油 8.98 ✓；水泥砂浆 1:2 318.54 > 1:2.5 289.39 > 1:3 271.91 恢复单调 ✓ |

9,066 个资源只有 1 个价，需要裁决的只有 179 个，其中价差 >2 倍的 56 个已进 `review_queue`。

### 2.3 泰国数据不是人材机价格库

THB 记录 3,883 条 = 1,864 条 `country='泰国'` + **2,019 条 country 字段损坏成字面 `'??'`**
（同价同日，是同一批数据的重复导入，`features` 里带 `project=/source_row=` 溯源信息）。

按专业分：专业分包/分包 2,551 + 间接费 968 都是 BOQ 综合子目与现场措施费；
人材机层级只有 材料 207 / 机械 93 / 劳务 49。**探针查证没有水泥、碎石、木材、柴油、电、水的单价。**

去重后 206 条候选，最终只有 22 个资源能作锚点。

### 2.4 「乘 1~2 倍」方向是反的

实测系数（FX = 5.0 THB/CNY）：

| 类别 | 标定系数 | 锚点数 | 说明 |
|---|---|---|---|
| 人工 | **0.781** | 9 | 泰国人工显著低于中国定额基价 |
| 材料 | **0.993** | 10 | 基本持平 |
| 机械 | **0.916** | 12 | 略低 |
| 机械/汽车起重机（族） | 0.769 | 8 | |
| 材料/钢筋（族） | 0.993 | 4 | |
| 人工/技工（族） | 0.781 | 6 | |

统一乘 1~2 会系统性高估。只有进口/加工类材料才可能高于 1，但数据里没有足够锚点支撑单独出系数。

### 2.5 机械台班单价不含燃料

C 册 4,164 条含柴油的定额中 4,162 条同时有台班行，燃料是独立材料行。
样例 `BJ21.23.4-12`（补缝板 C30）：普工 2.416 工日 + 混凝土 1.015 m3 + **柴油 1.0693 kg**
+ 小翻斗车 0.127 台班 + 混凝土搅拌机 0.063 台班。

→ 泰国裸租 `台月 ÷ 月班数` 直接作为台班单价基础，**不需要补燃料费**。

### 2.6 泰国人工锚点是 2012~2017 年的法定最低工资

46 条工日候选全部来自泰国劳动部「技能标准最低工资」公告，不是市场价。用法：

- 取 1/2/3 级中位数（400 / 505 / 602 THB/天）→ 映射到本库 普工/技工/高级技工
- 乘 `LABOR_ESCALATION = 1.30` 推到 2026（泰国全国最低工资 2012 约 300 → 2026 约 400 THB/天）
- 工长无锚点，按中国基线的 工长/高级技工 比例（369.6/201.6 = 1.83）外推

结果：普工 520 / 技工 656.5 / 高级技工 783.25 / 工长 1435.96 THB/工日。
工长折 4.3 万 THB/月，对泰国工长是合理量级。

### 2.7 GDS/泰华 项目的机械价是包干费率，只能用于标定

折算回月租都是整数，且同一数值跨多种机型：

| THB/台班 | = THB/月 | 覆盖机型 |
|---|---|---|
| 4615.38 | 120,000 | 汽车吊 / 挖掘机 / 压路机 / 平板车（4 种） |
| 3076.92 | 80,000 | 单钢轮压路机 / 升降车 / 发电机 / 双笼物料提升机（4 种） |
| 5000.00 | 130,000 | 挖掘机 / 随车吊（2 种） |

这是项目预算包干价，不是分机型市场价。若作直接赋价，25t/35t/50t 吊车会拿到同一个数，阶梯被压平
（实测 40t 923 CNY < 25t 964 CNY，非单调）。

→ 设计上分成两张表：`price_anchor`（输入，含仅标定用的包干价）与 `resource_price`（输出，最终价）。
包干价 `use_for_price = 0`，参与 Phase 3 标定但不赋价，具体吨位交给 L2 保持阶梯。
修正后吊车阶梯单调：5t 241 → 8t 377 → 12t 522 → 16t 704 → 20t 763 → 25t 1005 → 40t 1592 → 75t 2527 CNY/台班。

### 2.8 缺口的主导模式是近似重名资源，不是同族不同规格

库里存在大量近重名资源：`汽车式起重机`/`汽车起重机`、`板枋材`/`板方材`、
`标准砖240mm*115mm*53mm`/`标准砖240*115*53mm`、`砂子中粗砂`/`中粗砂`。

- 按族取中位数会出错：`汽车式起重机 16t` 拿到族中位数 3,408 CNY/台班，实际应为 704（偏高 5 倍）
- 按名称对齐（同类+同单位+同规格，Jaccard ≥ 0.7 且交集 ≥ 2 字）准确得多

阈值实测：0.5 太松（`塑料装饰条`→`塑料焊条`、`不锈钢腰线`→`不锈钢圆钢`）；0.7 干净。

### 2.9 艘班是唯一的硬缺口，无源可补

69 个资源、10,741 refs（占全部 2.9%，是 D 册机械的全部），既无中国基线也无泰国锚点：
拖轮 441kW、机动艇 44kW、方驳 600t、方驳吊机船组 30t、铁驳 50t、锚艇、打桩船……

试过的路都不通：

- `refers/norms_jts276-1/3-2019_excel.sqlite`、`三航局Laldia项目人工机械定额.sqlite`
  只有消耗量（`amount` 是数量不是单价），没有艘班单价
- 按 kW 从陆上台班机械外推：散度 20 倍（105kW → 552 元 vs 110kW → 27 元），可拟合样本仅 33 条，
  且驳船/打桩船与陆上机械结构不同

→ 留空并进 `review_queue`，如实报告。**不编造数字。**

## 6. 注意问题

### 6.1 阻塞性 / 需决策

1. **`FX_THB_PER_CNY = 5.0` 是假设值**，未核实。所有 THB 价与 CNY 等值都按它算，
   系数标定也用它。改汇率需重跑 Phase 3~5。
2. **Phase 5 会覆盖 `Norm` 的旧中国基价**（A册 2,812 条 / B册 12,468 / C册 9,501 / D册 3,650 / E册 13,476
   目前有非零 `norm_ManPrice`）。脚本会先快照到 `resource_master.norm_price_legacy`，
   但这仍是不可逆的语义变更：那 6 列的含义从「中国基价」变成「泰国基价」。
3. **L5 层占 11.4% refs，是最粗糙的一层**。同类同单位中位数会给出明显不合理的值，例如
   `混凝土搅拌站 120m3/h`、`混凝土输送泵车 70m3/h`、`钢筋弯曲机` 都拿到台班中位数 124.76 CNY；
   `板枋材`/`井室盖板`/`硬杂木` 都拿到 m3 材料中位数 608.09 CNY。按 refs 降序人工过头部约 100 项
   能显著改善，但尚未做。
4. **币种标签不符**：前端 `output/norms_browser.html` 与 `src/export_norms.py:384`
   的「参考单价」把这两列当「元」渲染，填入 THB 后标签会错。最小修法是表头加币种标注，
   **不在本次范围内**。

### 6.2 已知偏差 / 口径说明

5. **人工锚点是法定最低工资 × 1.30**，不是市场询价。`技工-安装工` 的中国基线 268.8 高于
   通用技工 168，但泰国侧统一取了技工值，导致该项比值 0.488 偏离其他人工项的 0.78（仅 19 refs，影响小）。
6. **泰国机械锚点是项目租赁价折算**，口径为「租赁月价 ÷ 26 班」，隐含机器满月工作。
   实际有闲置时，单位台班成本会高于此值。
7. **`'??'` 是 CostSpread 的数据质量问题**，不是本项目造成的：2,019 条 THB 记录的 `country`
   与 `country_en` 都是字面两个问号。建议在 CostSpread 侧修数据。
8. **混凝土锚点是 450ksc(≈C45) 对 `预拌混凝土 C40`**（最近强度，refs 仅 16）。
   C10~C30 的高 refs 条目靠族系数 0.993 派生。
9. Phase 5 的单位一致性校验 5 册全部通过（`Consumption.cons_Units` 与 `resource.res_Unit` 无一不符）。
10. B 册 4,050 条 `Consumption` 中 1,509 条无价，因为 B 册（通用安装）主材/设备占比高，按惯例留空。

## 10. 报价异常修正（2026-09-29）

触发：泰国包钢筋 φ10 内外是 33.2 泰铢/kg（肯尼亚 T4，6.64 元/kg），无规格/综合钢筋只有 10.12（印尼 T2，
