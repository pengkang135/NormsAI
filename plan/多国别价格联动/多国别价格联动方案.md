# 多国别价格联动方案

日期：2026-09-29　状态：已实现并验证（见文末「实施偏差记录」）

## 目标

顶部选一个国别（价格包）后，**价格库与定额库同步切换**：定额库里的人材机单价、子目人工/材料/机械/主材/设备费、综合价，以及 Excel 导出，都按所选价格包的价格和币种给出。

## 已确认的决策

| 问题 | 决定 |
|---|---|
| 同步范围 | 定额库浏览 + 综合单价表 Excel 导出。**不回写 `db/` 数据库文件**，切换即时生效 |
| 所选包缺价 | 该条目留空，标「本包未定价」，不编造数字、不回退到其他包 |
| 默认包 `th_2026` 与现有写死值不一致 | 以 `resource_price` 为事实源。约 3% 子项的显示价会从旧写死值变为价格库现值；本次不重新回写各册库 |

## 现状（探查结论）

- 价格包 3 个：`th_2026`（THB，active）、`cn_2026`（CNY）、`lk_2026`（USD），`resource_price` 按 `(res_ID, pack, price_date)` 存价。
- 定额库单价是**写死在各册库里**的泰国价：`Consumption.cons_Price`（THB）、`Norm` 的 `norm_ManPrice / MaterialPrice / MachinePrice / MainMaterialPrice / EquipmentPrice`（`norm_OtherPrice` 全为 0）。
- `Norm` 各价格列 = `Σ(Content.cont_Amount × Consumption.cons_Price)` 按 `cons_Style` 汇总：3→人工，4→材料，5→机械，6→设备，7→主材。抽样核对逐条一致。
- `Consumption.master_res_ID` 指向 `resource_master.resource`，覆盖率 100%（A 册 2440/2440）。A 册 `cons_UnitQuotiety` 全为 1，即消耗量单位与资源单位一致，包价可直接使用。
- **写死值已落后于价格库**：A 册 2440 条消耗量中 71 条与 `th_2026` 现价差异明显（如 XPS 保温板 4950 vs 2400，价格库日期 2026-08-23）。
- 写死 `th_2026` 或取「第一个 active 包」的位置：`start.py:641`（配比材料库）、`src/export_norms.py:_load_price_meta`。
- 价格库页面的包选择器目前只在「价格库」标签下显示（`output/norms_browser.html` `switchView`）。

## 设计

### 1. 全局国别状态（前端）

- 包选择器 `#packSelect` 与「i」口径按钮从价格库标签移到顶栏公共区，两个标签下都显示。
- 选中的包存 `localStorage`，刷新后保持；无记录时用 `/api/price/packs` 返回的 default。
- 定额库所有涉及价格的请求（`/api/items`、`/api/nrm-items`、`/api/export`）带上 `pack` 参数；切换包后重新加载当前章节。
- 定额库金额显示处标注币种（THB/CNY/USD），取自 `price_pack.currency`。现有 `元` 字样对价格类字段改为按包币种。

### 2. 后端价格覆盖层

新增 `src/pack_price.py`，职责单一：给定 `pack`，回答「某资源在该包的价格」，并提供子目重算。

- `get_price_map(pack) -> {res_ID: price}`：一次性读 `resource_price WHERE pack=?`，进程内缓存；以 `resource_master.sqlite` 的 mtime 作缓存失效键。同一 `(res_ID, pack)` 有多个 `price_date` 时取最新。
- `pack=None` 或包不存在时，取 `status='active'` 第一个包（与现有 `_default_pack` 同口径），并把该逻辑收敛到此模块，`price_api._default_pack` 与 `export_norms._load_price_meta` 改为复用。
- 覆盖规则（仅企业定额 A~E 册，即 `ENT_BOQ_DOC_KEYS`）：
  - 子项单价 = `price_map[master_res_ID]`；缺价为 `None`。
  - 子目 人工/材料/机械/设备/主材费 = `Σ(cont_Amount × 单价)`，缺价子项不计入，同时返回该子目的 `unpriced_count`。
  - 子目 `amount`（综合价）= 人工+材料+机械费（`other` 为 0），与现有 `base = man+mat+mach+other` 一致。
- `pack` 校验：不在 `price_pack` 注册表内 → 400。

### 3. 接口改动

| 接口 | 改动 |
|---|---|
| `/api/items`、`/api/nrm-items` | 新增可选 `pack`。企业 A~E 册走覆盖层（`_beijing_norm_items`）；响应字段结构不变，子项增加 `unit_price=null` 表示未定价，子目行增加 `unpriced_count`、响应带 `currency` |
| `/api/index` | 不变（不含价格） |
| `/api/export` | 请求体新增 `pack`；`export_norms.build_export_workbook` 单价按包覆盖，币种、定价日期/来源均取所选包 |
| 配比材料库 `_api_items_mix` | `p.pack = 'th_2026'` 改为所选包 |
| `/api/price/*` | 不变 |

不带 `pack` 时行为等同默认包，保证旧调用方（如 `pk-norms-export` 技能）无需改动即可工作。

### 4. 币种与说明

- 不做跨包币种换算，每个包按自身币种显示。
- 口径「i」按钮沿用 `price_pack.note`，定额库页面同样可见。

### 5. 范围外（第一期不做）

- `M册`（机械台班）`norms_item` 无价格列，无需覆盖。
- `N册` 中以 `MB` 开头的材料用量子目与 `JTS`/北京等参考库的价格列：写死值，暂不联动，前端在这些库下显示「价格不随国别切换」的提示。
- 不回写数据库、不新增价格包。

## 验收标准

1. 切到 `cn_2026`，任选 A/B/C 册各一个子目：子项单价与 `resource_price(pack='cn_2026')` 逐项一致，费用汇总等于 `Σ(消耗量×单价)`，币种显示 CNY。
2. 缺价条目（如 B 册设备、主材）单价为空并显示「本包未定价」，子目提示未定价项数。
3. 同一子目在 `th_2026 / cn_2026 / lk_2026` 间切换，单价、费用、币种随之变化，切回后与首次一致。
4. 刷新页面后国别保持；价格库标签与定额库标签的包始终一致。
5. `/api/export` 带 `pack` 导出的 Excel，币种、单价与页面显示一致；不带 `pack` 时与默认包一致。
6. `th_2026` 下，未受「写死值落后」影响的子项（约 97%）显示值与改动前一致；受影响的子项差异清单落到 `temp/` 备查。
7. 浏览类接口现有字段不减少、不改名。

## 测试策略

- 后端单元测试（`pytest`，测试文件位置在实施计划中确定）：`get_price_map` 缓存与失效、最新价选取、缺价留空、子目汇总与 `Σ` 对账、非法 `pack` 400。
- 对账脚本：全册遍历，逐子目对比「覆盖层重算」与「库内写死的 Norm 列」，输出差异清单（预期差异仅来自那 ~3% 落后项）。
- 前端手工验证：切换三个包、刷新保持、导出与页面一致。

## 风险

- 服务是单线程 `TCPServer`，覆盖层必须走内存缓存，避免每次请求全量扫 `resource_price`；章节级重算量小（单章几百条消耗量），可接受。
- 「写死值落后于价格库」是既有数据问题，本次只暴露不修复；如需彻底一致，另起任务重灌各册 `cons_Price` 与 `Norm` 汇总列（`python scripts/build_resource_usage.py` 之外还需价格回写脚本）。
- 新增国家包后，需保证 `price_pack.currency` 已填，否则币种显示为空。

## 实施偏差记录

- **导出说明页**：现有导出没有「说明」sheet，未新增。所选包体现在「人材机价格表」的币种列（泰铢/人民币/美元）、备注列，以及缺价警告和 `X-Export-Stats`（含 `pack`、`currency`）里；文件名带包 id。
- **税额口径**：`price_excl` 直采锚点与「÷1.07 推算除税价」只属于泰国包（`th_2026`）。其他包若 `resource_price.price_excl` 有值则用之，否则除税价=单价、税金留 0，不编造税率。
- **`_beijing_norm_rows`** 无调用方，未改。
- **`/api/items` 响应**：仍是数组。币种不放在响应里，由前端按所选包的 `currency` 显示；子目名称行新增 `unpriced_count`，缺价子项新增 `unpriced: true`。
- **写死值落后量**：设计时 A 册约 71/2440 条与价格库现价不一致；实施时各册库与 `resource_master` 已被另一进程重新同步（2026-09-29 10:30~10:33），现为 A 册 8、C 册 14、E 册 6 条，B/D 册 0 条（明细 `temp/pack_drift_th_2026.csv`，脚本 `temp/scripts/pack_drift_report.py`）。
- **测试**：`tests/test_pack_price.py`（14 项，`python -m pytest tests/test_pack_price.py`）。
